# ChargeShare

Peer-to-Peer Wallbox-Sharing, komplett in Kotlin Multiplatform.

## Module (geplant)
- `shared/` - Domain, Datenmodelle, Ktor-API-Client, Business-Logik (Android, iOS, Web)
- `composeApp/` - Compose Multiplatform UI fuer Android und iOS
- `server/` - Ktor-Backend (PostgreSQL, Stripe Connect, OCPP 1.6)
- `web/` - Compose fuer Web (Wasm)
- `docs/` - Konzept und Design
- `legacy/` - Referenz: bisheriges Go-Backend und SwiftUI-App (werden nach der Migration entfernt)
